# Backend — planned, not implemented

The current package contains **no backend source code to preserve**. The existing application is frontend-only. The planned FastAPI/PostgreSQL stack will be developed here once endpoints, data models, migrations, secure authentication and authorization have been reviewed. Do not invent or expose live patient APIs using demonstration frontend records.

The separate private local Node/R research harness now enforces the shared
pre-assessment screening policy before RSF inference. It is not a production
application backend or authenticated clinical service. See
[pre-assessment screening](../docs/PRE_ASSESSMENT_SCREENING.md) for its contract,
source-version limitations, and the distinction from the planned backend.
