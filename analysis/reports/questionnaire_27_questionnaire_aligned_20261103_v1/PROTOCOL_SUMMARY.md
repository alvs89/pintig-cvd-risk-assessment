# Questionnaire-aligned synthetic dataset summary

Generated by `analysis/scripts/rsf27_questionnaire_aligned_v1/build_dataset.py`
with fixed seed `27110317`.

- **Dataset:** `pintig_framingham_27predictors_QUESTIONNAIRE_ALIGNED_PROXY_EXPERIMENTAL.csv`
- **Shape:** 4,191 participants × 33 columns (27 predictors + 6 metadata columns)
- **Outcome/fold linkage:** copied exactly from the recovered proxy dataset after feature generation; 369 recorded-CVD proxy events, 218 death-before-recorded-CVD proxy events, and 3,604 censored participants.
- **Observed baseline fields preserved:** age, sex, systolic/diastolic BP, heart rate, hypertension, BP medication, diabetes, and current smoking intensity.
- **Synthetic/derived fields:** all remaining response-derived predictors, including waist/hip, medication context, family history, alcohol, former smoking, passive smoking, activity, sitting, Food6 diet, stress, sleep, residence, and SES.

The sidecar `SYNTHETIC_questionnaire_responses.csv` is a reproducible synthetic
response record. It is not an observation from a Framingham or Philippine
participant. Its generation code reads only allow-listed baseline Framingham
columns and never reads outcomes, follow-up time, or folds.

SES uses categorical education, income-category representatives, and
square-root household-size adjustment. The static dataset score describes the
synthetic cohort. The RSF experiment recomputes PCA from each training split
before scoring its validation split.
